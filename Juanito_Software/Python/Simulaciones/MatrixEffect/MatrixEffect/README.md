# MatrixEffect

**© 2025 JuanitoSoftware&Games** — Licencia GPLv3

Proyecto que implementa el icónico efecto visual de lluvia de código verde de Matrix en dos variantes:

| Variante | Descripción |
|---|---|
| [`consola/`](./consola/) | Animación en terminal con intro de boot, efectos glitch y banda sonora |
| [`FondoPantalla/`](./FondoPantalla/) | Fondo de escritorio animado en tiempo real usando pygame (solo Windows) |

## Estructura del proyecto

```
MatrixEffect/
├── consola/          # Versión para terminal (Windows/Linux)
└── FondoPantalla/    # Versión fondo de escritorio (Windows)
```
