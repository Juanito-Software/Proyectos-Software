# 🧠 Ruta de libros para convertirte en programador sólido

## 1) 🧩 Mentalidad profesional (primero de todo)

### **The Pragmatic Programmer**

Es el libro más importante de esta lista para tu momento actual.

Qué te da:

- Cómo piensan los programadores senior
    
- Cómo evitar deuda técnica desde el inicio
    
- Buenas prácticas reales (no teoría bonita)
    
- Cómo trabajar mejor con herramientas, debugging, automatización
    

👉 Este libro cambia tu “forma de programar”, no solo tu código.

---

## 2) 🧼 Calidad de código (nivel industrial)

### **Clean Code – Robert C. Martin**

Qué aprendes:

- Cómo escribir código legible a escala
    
- Nombres, funciones, clases bien diseñadas
    
- Antipatrones típicos que ahora mismo seguro ya has visto en proyectos reales
    
- Cómo mantener proyectos vivos sin que se degraden
    

💡 Opinión clara:  
Este libro es casi obligatorio si quieres trabajar como dev serio en equipo.

---

## 3) 🏗️ Arquitectura de software (el salto grande)

### **Clean Architecture – Robert C. Martin**

Aquí es donde empiezas a pensar como “arquitecto”.

Conceptos clave:

- Separación de capas real (no solo teoría de clase)
    
- Independencia de frameworks
    
- Dependencia invertida
    
- Sistemas mantenibles a largo plazo
    

👉 Este libro te hace ver por qué muchos proyectos en empresa acaban siendo difíciles de mantener.

---

## 4) 🧱 Diseño orientado a objetos avanzado

### **Head First Design Patterns**

### **Design Patterns (GoF)**

Orden recomendado:

1. Head First (entender)
    
2. GoF (formalizar)
    

Aprendes:

- Observer, Factory, Strategy, Command, State…
    
- Cómo evitar estructuras rígidas
    
- Cómo diseñar sistemas extensibles
    

💡 Opinión:  
En Unity esto es oro puro. Mucho de lo que falla en proyectos de juegos es falta de patrones.

---

## 5) ⚙️ Rendimiento y estructuras profundas

### **Introduction to Algorithms (CLRS)**

Este ya es nivel “ingeniero fuerte”.

Te aporta:

- Complejidad real (Big-O a nivel serio)
    
- Estructuras de datos avanzadas
    
- Algoritmos clásicos (grafos, búsqueda, ordenación…)
    

👉 No es para leer rápido. Es libro de consulta + estudio.

---

## 6) 🎮 Bonus (muy importante en tu caso)

### **Game Programming Patterns – Robert Nystrom**

Aunque es de juegos, refuerza arquitectura:

- Component pattern
    
- Event systems
    
- Game loops
    
- State machines
    

👉 Esto conecta perfecto con Clean Architecture + Clean Code.

---

# 🧭 Orden recomendado (importante)

Si quieres hacerlo eficiente:

1. Pragmatic Programmer
    
2. Clean Code
    
3. Game Programming Patterns (en paralelo con el 2 si quieres algo más práctico)

6. GoF (solo si quieres profundidad real)
    
7. CLRS (como libro de referencia, no de lectura lineal)
